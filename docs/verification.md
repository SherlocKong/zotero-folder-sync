## 重复执行测试

通用检查命令见[仓库说明](../README.md)。应用层断言位于 [integration.js](../tests/zotero/integration.js)。运行器检查独立 Profile 和专用测试标记后，才清理并重建该测试库中的合成内容。

1. 使用 [prepare_zotero_test.py](../scripts/prepare_zotero_test.py) 创建一个全新的测试目录。
2. 以该目录下的 `profile` 启动独立 Zotero 实例，将 XPI 安装到该实例。
3. 在测试实例的开发环境中加载 `integration.js` 并调用 `FolderSyncIntegration(测试目录绝对路径)`，提供 Zotero、Services、Ci、PathUtils、IOUtils 运行时对象。
4. 检查测试目录生成的 `zotero-results.json`，确认 `passed` 为 true。
5. 通过该 Profile 的连接文件执行 CLI，核验健康检查、计划及任务轮询。

正式资料目录仅执行只读树识别回归；本轮未向真实 Zotero 资料库写入。

## 当前版本边界

首版提供 PDF 链接导入和分类维护。文件移动归档、路径迁移向导、规则模板导入导出在后续版本实现。实际应用层目前只声明 macOS 与 Zotero 10.0.9 的验证结果；跨平台核心测试与实际应用测试分别记录。

状态和目录绑定当前保存在 Profile 内的同一份原子配置文件中，以保持配置修订一致；模板导出阶段会移除本机路径和分类绑定。
